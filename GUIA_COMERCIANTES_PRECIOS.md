# Guía para Comerciantes: Manejo de Precios y Unidades

## Estrategia Simplificada de Precios

### ✅ **Enfoque Recomendado: Un Producto = Un Precio Fijo**

En lugar de conversiones complicadas, cada producto tiene un precio fijo por su unidad específica.

## Ejemplos Prácticos

### 🍅 **Tomates - Múltiples Opciones**

**Opción 1: Venta por Libra**
- Nombre: "Tomate"
- Precio: $2.50
- Unidad: Libra
- Resultado: Cliente paga $2.50 por cada libra

**Opción 2: Venta por Unidad**
- Nombre: "Tomate (individual)"
- Precio: $0.25
- Unidad: Unidad
- Resultado: Cliente paga $0.25 por cada tomate

### 🧅 **Cebollas - Diferentes Presentaciones**

**Venta por Kilo**
- Nombre: "Cebolla"
- Precio: $1.80
- Unidad: Kilogramo
- Resultado: Cliente paga $1.80 por cada kilo

**Venta por Bolsa**
- Nombre: "Cebolla (bolsa 3 lb)"
- Precio: $5.00
- Unidad: Bolsa
- Resultado: Cliente paga $5.00 por cada bolsa

### 🥚 **Huevos**

**Venta por Docena**
- Nombre: "Huevos frescos"
- Precio: $3.00
- Unidad: Docena
- Resultado: Cliente paga $3.00 por cada docena

## Ventajas de Este Sistema

### 🎯 **Para el Comerciante**
- **Control total** sobre precios
- **Sin conversiones** complicadas
- **Flexibilidad** para diferentes presentaciones
- **Fácil gestión** de inventario

### 👥 **Para el Cliente**
- **Claridad total** en precios
- **Sin confusiones** de conversión
- **Precios transparentes**
- **Fácil comparación** entre opciones

## Estrategias de Venta

### 1. **Productos Populares en Múltiples Unidades**
```
Tomate por libra - $2.50 c/libra
Tomate individual - $0.25 c/unidad
Tomate por kilo - $5.50 c/kilo
```

### 2. **Productos por Peso vs Empaquetados**
```
Cebolla suelta - $1.80 c/kilo
Cebolla en bolsa - $5.00 c/bolsa (3 kilos)
```

### 3. **Productos Premium vs Económicos**
```
Manzana premium - $0.50 c/unidad
Manzana económica - $3.00 c/kilo
```

## Recomendaciones

### ✅ **Hacer**
- Crear productos separados para diferentes unidades
- Usar nombres descriptivos ("Tomate individual", "Tomate por libra")
- Establecer precios competitivos por unidad
- Mantener consistencia en la calidad

### ❌ **Evitar**
- Intentar conversiones automáticas
- Precios confusos o poco claros
- Demasiadas opciones para el mismo producto
- Cambiar precios frecuentemente

- Precios claros y transparentes

- Control total de márgenes de ganancia

### 📊 **Operativos**

- Fácil seguimiento de ventas

Este sistema es **más simple, más claro y más efectivo** que las conversiones automáticas. Permite al comerciante tener control total sobre su negocio mientras ofrece una experiencia transparente al cliente.
